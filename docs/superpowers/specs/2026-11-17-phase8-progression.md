# Phase 8 — Authoritative RPG Progression, Evidence and Profession

Base `master` 10cb9ca2e5351c2c7b0635189a2dde403733ba35, isolated branch `feat/rpg-phase8-character-gear-20261117`.

The existing `story-rpg-checks.js` already models skills, backgrounds, perks, grades, health and mood with exact 216-outcome 3d6 odds, and accepts explicit `item` for evidence. Current gaps: collectible story evidence does not affect ordinary context checks unless callers explicitly pass it; `S.jobTier` alone can grant the labor profession modifier even when no active employment contract exists. This phase adds an additive `rpg-progression.js` adapter **after** canonical 3d6 checks, using `World.storyItems` as existing unique owned evidence and `EmploymentSystem.activeForPerson(world,'subject')` as the sole employment authority. The adapter never persists an equipment table or changes the grade/perk system. Auto selection uses a strict curated domain-specific catalogue: career_portfolio→labor +2; career_letter→social +1; grey_duplicate→bureau +2; grey_testimony→bureau +1; ward_notice→bureau +1. Higher evidence wins, ties sort by stable ID. Explicit item takes precedence, including an explicitly missing item (no auto fallback). Auto evidence is optionally suppressed via `autoEvidence:false`. Preview and resolution are transformed through identical options, preserving deterministic 3d6, all base modifiers and clamp −4..+4. Contract tier≥3 grants profession bonus even if legacy S projection is stale; no active contract means none.

Provide read-only `RPGProgression.evidenceFor` for the existing Stories “STORY GEAR” panel; show domain and bonus without a new equipped/owned object. Tests cover missing/stale items, explicit priority, contract switch and unemployment, exact 216-state vs injected dice, save/reload, cap and accessible 320/390/768/1440 mobile. Never modify maps, locations, travel or their branches.
